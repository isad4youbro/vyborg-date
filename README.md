## 🇬🇧 English

### Overview

`Vyborg Date` is a small interactive single-page website designed as a digital invitation to a day in Vyborg.

The project focuses on a lightweight experience: custom copy, visual assets, responsive styling and browser-side interactions without a backend requirement for the deployed version.

### ✨ Features

- single-page interactive experience;
- responsive layout;
- custom text and visual assets;
- client-side JavaScript interactions;
- GitHub Pages deployment;
- optional local Python server.

### 📁 Project structure

```text
vyborg-date/
├── images/                 # visual assets
├── index.html              # page markup
├── style.css               # main styles
├── mobile-fix.css          # responsive adjustments
├── script.js               # interactions
├── main.py                 # optional local server
└── README.md
```

### 🚀 Run locally

You can open `index.html` directly or use the included Python helper:

```bash
python main.py
```

The deployed version uses GitHub Pages and does not require the Python file.

### 🌐 Deployment

The site can be published from the repository's `main` branch using GitHub Pages.

Live version:

https://isad4youbro.github.io/vyborg-date/

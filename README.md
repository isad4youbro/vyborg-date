# vyborg-date

приглашение на свидание в выборг, 30 июля.

## ссылка на сайт

https://isad4youbro.github.io/vyborg-date/

(появится после того как в Settings → Pages включишь публикацию из ветки `main`, папка `/ (root)`)

## структура

- `index.html`, `style.css`, `script.js` — сам сайт
- `images/` — фото (свои + выборгские)
- `main.py` — нужен только для локального запуска (`python main.py`), на GitHub Pages не используется и грузить его не обязательно
